# परिवर्तन सूची

Episteme के सभी उल्लेखनीय परिवर्तन इस फ़ाइल में दस्तावेज़ित किए जाएंगे।

प्रारूप [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) पर आधारित है,
और यह प्रोजेक्ट [Semantic Versioning](https://semver.org/spec/v2.0.0.html) का पालन करता है।

## [Unreleased]

### परिवर्तित

- CLI: `explore` का नाम बदलकर `search` किया गया (पुराना नाम अप्रचलित उपनाम के रूप में काम करता है)
- CLI: `mcp` और `api` अब अपने पूर्ण सेवा जीवनचक्र का प्रबंधन करते हैं (`start`, `stop`, `restart`, `status`, `enable [--now]`, `disable [--now]`)
- CLI: `service` शीर्ष-स्तरीय कमांड अप्रचलित है — इसके बजाय `mcp start/stop/restart/status/enable/disable` का उपयोग करें
- CLI: `mcp --http` अप्रचलित है — HTTP डेमन मोड के लिए `mcp start` का उपयोग करें
- CLI: `launchd-install/uninstall/status` अप्रचलित है — इसके बजाय `mcp enable/disable/status` का उपयोग करें
- `enable/disable` अब क्रॉस-प्लेटफ़ॉर्म है: macOS (launchd) और Linux (systemd यूज़र यूनिट)

### जोड़ा गया

- `api start/stop/restart/status/enable/disable` — REST API डेमन जीवनचक्र प्रबंधन
- `mcp enable` के लिए Linux systemd यूज़र यूनिट जनरेशन

- **Claude Code के लिए MCP HTTP ट्रांसपोर्ट** — ट्रांसपोर्ट चयनकर्ता TUI, HTTP डिफ़ॉल्ट, launchd स्वतः-सक्षम
- **एजेंट प्रॉम्प्ट स्वतः-स्थापना** — `epis install` Episteme एजेंट प्रॉम्प्ट्स को `~/.claude/agents/` में कॉपी करता है
- **एंटिटी विवरण** — विवरण फ़ील्ड Markdown स्रोत फ़ाइलों से स्वतः निकाला गया, Web व्यूअर विस्तार पैनल में दिखाया गया
- **बेंचमार्क विज़ुअलाइज़ेशन SPA** — ट्रेंड विश्लेषण, क्वेरी ब्रेकडाउन डैशबोर्ड
- **Web व्यूअर पुनः डिज़ाइन** — Sankey डायग्राम लेआउट, साइडबार ट्री, विवरण पैनल, सबग्राफ पठनीयता सुधार
- **MCP कॉन्फ़िग अपसर्ट** — `epis install` पुनः चलाने पर कॉन्फ़िग भिन्न होने पर ट्रांसपोर्ट अपडेट करता है (stdio ↔ HTTP)
- **MCP YAML कॉन्फ़िग** — `config.yaml` में `mcp.host` / `mcp.port` (yaml → env फ़ॉलबैक)
- **मॉनिटरिंग** — env के माध्यम से नेटिव और रिमोट Prometheus स्क्रेप टारगेट समर्थन
- **CI हार्डनिंग** — cargo audit, gitleaks, SBOM जनरेशन, पिन किए गए Action SHA
- **रिलीज़ पाइपलाइन** — Windows टारगेट, crates.io प्रकाशन, Homebrew टैप
- **God मॉड्यूल आर्किटेक्चर निदान उदाहरण** `examples/` में

### परिवर्तित

- **स्थापना विज़ार्ड** — सभी चरणों (ट्रांसपोर्ट, Redis, टेलीमेट्री) को फ़ुलस्क्रीन TUI में माइग्रेट किया गया
- **स्थापना प्रवाह** — सीडिंग के बाद स्वतः RAG इंडेक्स बनाता है, DB पहले से मौजूद होने पर छोड़ देता है
- **ज्ञान ग्राफ** — क्रॉस-एंटिटी सिमेंटिक संबंधों के साथ समृद्ध
- **लाइसेंस** — MIT → Apache-2.0

### सुधारित

- टेलीमेट्री के लिए समकालिक `main()` में Tokio रनटाइम पैनिक
- खोज गुणवत्ता — NDCG माप बग हल, hit@1 सटीकता 100% तक सुधारित
- खोज रिकॉल — क्रॉस-टाइप बूस्टिंग, स्पार्स एंटिटी हैंडलिंग, इंटेंट समानार्थी शब्द
- fastembed मॉडल कैश को `~/.episteme/models` पर पिन किया गया
- launchd बूटस्ट्रैप UID प्रतिस्थापन और पोर्ट-उपयोग-में हैंडलिंग
- CORS ओरिजिन अब `EPISTEME_CORS_ORIGINS` के माध्यम से कॉन्फ़िगर करने योग्य हैं

## [0.1.0] - 2026-05-03

### जोड़ा गया

- **संपूर्ण Rust पुनर्लेखन** — Python कोडबेस का आदर्श Rust के साथ पूर्ण प्रतिस्थापन
- **षटकोणीय आर्किटेक्चर** — `ports/` (traits), `domain/` (व्यावसायिक तर्क), `adapters/` (इंफ्रास्ट्रक्चर), `server/` (HTTP)
- **GenericParser फ़्रेमवर्क** — 8 ब्रेस-आधारित पार्सर्स को `ParserConfig` के साथ `GenericParser` में समेकित; regex पैटर्न `OnceLock` के माध्यम से `Box::leak` के साथ कैश किए गए
- **Python AST पार्सिंग** — सटीक Python स्मेल पहचान के लिए `rustpython-parser` (Long Method, Large Class, God Object)
- **TieredAccum + build_detection()** — `detectors.rs` में 14 समान स्मेल पहचान निर्माणों को डीडुप्लिकेट किया (1,253 → 591 पंक्तियाँ)
- **MCP मॉड्यूल विघटन** — `EpistemeMCP` (675 पंक्तियाँ) को `mcp_search`, `mcp_graph`, `mcp_analysis` सेवाओं में विभाजित किया
- **CLI कमांड विघटन** — `main.rs` (1,741 पंक्तियाँ) को `commands/` मॉड्यूल में `cli.rs` के साथ clap परिभाषाओं के लिए विभाजित किया
- **API हैंडलर डीडुप्लिकेशन** — डुप्लिकेट `search`/`search_post` को साझा `do_search()` में विलीन किया
- **16 स्मेल डिटेक्टर फ़ंक्शन** — 14 से बढ़ाए गए, सभी GoF स्मेल श्रेणियों को कवर करते हैं
- **17 REST API एंडपॉइंट** — हेल्थ प्रोब, Prometheus मेट्रिक्स, CORS, रेट लिमिटिंग
- **रेट लिमिटर TTL निष्कासन** — MAX_BUCKETS=10,000 जिसमें 1-घंटे TTL असीमित मेमोरी वृद्धि को रोकने के लिए
- **ReDoS शमन** — टर्नरी ऑपरेटर regex को `[^:]+` से `[^:\n]{1,50}` तक सीमित किया
- **स्थानीय एम्बेडिंग** — zero-config सिमेंटिक खोज के लिए fastembed (ONNX Runtime)
- **संवादात्मक स्थापना विज़ार्ड** — crossterm के साथ TUI, vim कीबाइंडिंग, अल्टरनेट स्क्रीन
- **वितरण पैकेजिंग** — स्वचालित DB बूटस्ट्रैप के साथ रिलीज़ आर्काइव निर्माण के लिए `episteme dist` कमांड
- **क्रॉस-प्लेटफ़ॉर्म CI** — linux/macOS (x86_64 + aarch64) के लिए GitHub Actions रिलीज़ वर्कफ़्लो
- **मल्टी-स्टेज Dockerfile** — Rust बिल्डर + स्लिम Debian रनटाइम

### परिवर्तित

- **भाषा**: Python 3.11+ → Rust (संस्करण 2024)
- **Web फ़्रेमवर्क**: FastAPI → axum
- **डेटाबेस**: Python sqlite3 → rusqlite (बंडल किया गया)
- **एम्बेडिंग**: sentence-transformers/PyTorch → fastembed/ONNX Runtime
- **CLI**: argparse → clap (derive)
- **सभी regex पैटर्न कैश किए गए** — वैश्विक `REGEX_CACHE` के माध्यम से हॉट पाथ पर शून्य पुनर्संकलन

- ChromaDB निर्भरता
